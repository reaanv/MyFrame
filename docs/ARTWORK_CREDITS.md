## Paintings downloaded later

With *New paintings over Wi-Fi* switched on (Settings → Media), MyFrame downloads more public-domain paintings
from the Met's Open Access API, a few per day, up to a cap of 300. It only accepts works the Met marks as
public domain, and records the same title, artist and credit line for the caption.
